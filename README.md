# LEARNINGPLAYWRITE3X

A JavaScript learning playground — hands-on examples covering the fundamentals of JavaScript, one chapter at a time.

## Chapters

| Folder | Topic |
|--------|-------|
| `00_chapter_Genai` | Getting started — hello world examples |
| `01_chapter_javascript` | JavaScript basics |
| `03_chapter_identifier` | Identifiers |
| `05_chapter_operators` | Operators (assignment, arithmetic, comparison, logical, and common confusions) |

## IQ Notes

The `IQ_notes` folder holds concept explainers written as markdown — each one breaks down a programming concept with comparison tables, code examples, and visual diagrams.

Ask me a question about any programming concept and I'll create an explainer file in that folder.

## Getting Started

Run any example with Node.js:

```bash
node hello.js
node 05_chapter_operators/01_datatype.js
```

## Repository Setup

This repo is initialized with Git and contains a portable Git installation for local use. HTTPS operations (push/clone/fetch) may be restricted by the local Application Control policy.
